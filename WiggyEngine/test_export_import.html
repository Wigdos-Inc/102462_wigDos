🎮 How to Test

  1. Open the Editor: Open WiggyEngine Editor
  2. Create a Test Project:
    • Click "Nieuw Project"
    • Enter a project name (e.g., "TestGame")
    • Click "Maken"
  3. Add Some Content:
    • Click "+ GameObject" to add objects
    • Modify properties in the Inspector
  4. Save the Project:
    • Click "Opslaan" in the menu bar
    • File will download as ProjectName.wigp
    • ✅ Should see "Project opgeslagen" notification
  5. Build the Game:
    • Click "🔧 Bouwen" button
    • Wait for "Project wordt gebouwd..." notification
    • File will download as ProjectName_game.html
    • ✅ Should see success alert with statistics
  6. Reload and Import:
    • Refresh the editor page (F5)
    • Click "Project Openen"
    • Select your saved .wigp file
    • ✅ Should see "Project ... succesvol geladen!" alert
    • ✅ All your gameObjects and settings should be restored
